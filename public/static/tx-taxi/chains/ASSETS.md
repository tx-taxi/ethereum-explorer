# Chain Icons

These icons identify external networks in the tx.taxi chain menu. The menu
renders each asset in a fixed 20 by 20 pixel box.

## Bitcoin

`btc/icon.png` was copied byte-for-byte from the shared tx.taxi chain asset at
`frontend/src/resources/chains/btc/icon.png` in `tx-taxi-v2`, where it was added
in commit `334da29a2369222f4345278688b9f83bc0e94ad9` on 2026-05-22. That repository
does not record an upstream source for the image.

SHA-256: `3e44b4d63803886a836623ef33dd9300ed8e5660945457d616ec92aa1b7534b8`

## Monero

`xmr/icon.png` is the unmodified white-M Monero symbol from the official press
kit, copied byte-for-byte from the shared tx.taxi chain asset:

- https://www.getmonero.org/press-kit/
- https://www.getmonero.org/press-kit/symbols/monero-symbol-on-white-480.png

The shared asset records a retrieval date of 2026-09-19.

SHA-256: `531faec93058e37338ddd860191d4677a1a77778ccfa125de2232c4cd2554fb1`

## Ethereum
